# Cereal Crispins 🎮

Repositorio oficial para la documentación, control de versiones y gestión de archivos del videojuego de plataformas y arcade en 2D, **Cereal Crispins**, desarrollado bajo el motor **Godot 4.2 LTS**.

## 📝 Descripción del Proyecto
**Cereal Crispins** es un videojuego arcade de plataformas 2D diseñado con una arquitectura modular y desacoplada basada en nodos y componentes. El proyecto surge como una propuesta técnica orientada a buenas prácticas de desarrollo de software, implementando un sistema limpio de señales, gestión de escenas independientes y control de versiones mediante Git y GitHub.

## 🛠️ Tecnologías y Herramientas Utilizadas
- **Motor de juego:** Godot 4.2 LTS (Lenguaje de scripting: GDScript).
- **Control de versiones:** Git / GitHub (Gestión de ramas y commits descriptivos).
- **Diseño y Documentación:** TDD (Technical Design Document), diagramas UML (Clases y Secuencia) modelados para la estructura lógica del juego.

## 📂 Estructura del Repositorio
El proyecto se encuentra organizado bajo una jerarquía estricta para separar recursos multimedia, código y documentación académica:
- `Assets/` - Recursos visuales, sprites de personajes, elementos de entornos y archivos de audio.
  - `Characters/` - Sprites y elementos visuales del protagonista y entidades.
  - `Environments/` - Plataformas, fondos y componentes de los escenarios.
  - `Audio/` - Efectos de sonido (SFX) y música de fondo (BGM).
- `Scenes/` - Escenas independientes y niveles del juego con extensión `.tscn`.
- `Scripts/` - Código fuente modular en GDScript (`.gd`) para controladores y lógica del sistema.
- `Docs/` - Documentación técnica, diagramas de arquitectura y evidencias de diseño.
